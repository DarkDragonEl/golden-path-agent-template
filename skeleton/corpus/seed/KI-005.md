# Known Error: CI Pipeline Timeout on Large Image Builds

**Symptom:** The build stage times out on pipelines building unusually
large container images, even though the same pipeline definition works
for smaller images.

**Root cause:** Large image builds occasionally exceed the CI runner's
configured per-job timeout, particularly when a build also has to pull a
large base image layer that hasn't been cached on that runner yet.

**Workaround:** Split the image build into smaller layers where possible,
or pre-warm the runner cache with the base image ahead of time. If the
timeout persists, request a per-pipeline timeout exception from the CI
Platform Team Lead rather than repeatedly retrying — this is handled
case-by-case, not as a blanket policy change.
