# Service Catalog Entry: Managed Database Namespace Add-on

Provisions a managed database instance inside a team's namespace, with
platform-managed lifecycle (provisioning, credentials, and routine
maintenance) instead of the team running the database themselves.

**What it provisions:** a managed database instance sized to a team-chosen
tier, network-restricted to the requesting namespace by default, with
credentials issued automatically on provisioning.

**Backups:** the add-on takes database backups as part of platform-managed
maintenance; no documented backup frequency is specified for the Managed
Database Namespace Add-on in this entry — teams with a specific recovery-
point requirement should confirm current backup behavior with Platform
Engineering rather than assuming a figure.
