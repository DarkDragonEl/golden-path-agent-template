# Provenance

This scaffold is original work, informed by structural patterns observed in
prior internal engagements (agent orchestration shape, container/GitOps
packaging conventions, evaluation-harness design). No client code, secrets,
configuration values, or literal file contents from any other engagement
were copied into this repository.

The reuse map recording which patterns were observed and how they were
adapted is an internal artifact of the private parent workspace this
repository was developed alongside — it is not part of this public repo
and is not published here. This page exists so whoever inherits this repo
has a clear, self-contained record of its origin without depending on
that internal artifact.
