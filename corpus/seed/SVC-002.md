# Service Catalog Entry: CI Pipeline Template (Build-Test-Scan-Promote)

Sets up a build-test-scan-promote pipeline for a new repository in one
step, so a team doesn't have to hand-assemble CI configuration from
scratch.

**What it sets up:** a build-test-scan-promote pipeline — it follows the
CI Pipeline Reference Architecture directly, wiring the same four stages
(build, test, scan, promote) that architecture defines, pre-configured
with the platform's standard tooling for each stage.

**How to request it:** publish or instantiate this entry via the service
catalog; the resulting pipeline definition can be customized afterward,
but starts from the reference architecture's stage sequence, not a
custom one.
