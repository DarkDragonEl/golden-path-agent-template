# Production Access Request Procedure

This procedure governs how a team member requests access to production
systems.

The Identity and Access Team Lead reviews production access requests.
Every request is reviewed individually against the requester's role and
the specific production resource being requested — there is no
auto-approval path for any requester, including pilot users; every
production access request, regardless of who submits it, waits for an
explicit review and decision from the Identity and Access Team Lead.

Typical review turnaround is a few business days, longer if the request
requires consultation with the resource owner. Requests are tracked as
ITSM service requests so status can be checked at any time without
contacting the Identity and Access Team directly.
