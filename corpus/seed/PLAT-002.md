# Namespace Request and Quota Policy

This policy governs how namespaces are requested and how their resource
quotas are set and changed.

Every namespace is created with a default resource quota. A team that
needs a quota increase above the default limit must submit a request; the
Namespace Governance Owner approves quota increases above the default
limit. Requests are reviewed against the quarterly capacity-planning
cycle — a request may be approved outside that cycle only if the
Namespace Governance Owner judges it urgent enough to warrant an
out-of-cycle review.

Quota increases above the default limit are never automatically approved
without review; every such request requires an explicit decision from the
Namespace Governance Owner, recorded against the request.
