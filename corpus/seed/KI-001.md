# Known Error: CI Runner Cache Corruption on Concurrent Builds

**Symptom:** CI pipeline builds fail intermittently with cache-related
errors when multiple builds run concurrently against the same shared
runner pool. Failures are not consistently reproducible on retry.

**Root cause:** Shared CI runner caches can become corrupted under
concurrent writes from multiple simultaneous build jobs, since the cache
layer does not fully isolate writes between jobs sharing the same runner.

**Workaround:** Retry the failed build. If the failure recurs, clear the
affected runner's cache manually and retry once more; this resolves the
symptom in nearly all cases until a permanent per-job cache isolation fix
ships. Tracked in the ITSM known-error record for CI Platform Team
triage.
