# Namespace Onboarding Procedure

This procedure describes the steps a team follows to get a new namespace
provisioned.

1. Submit a namespace request referencing the Namespace Request and Quota
   Policy, including the requesting team, the intended workload, and the
   requested default quota (or confirmation that the standard default is
   sufficient).
2. Await approval from the Namespace Governance Owner. The Owner reviews
   the request against current capacity and existing namespace naming
   conventions before approving.
3. Once approved, the namespace is provisioned automatically from the
   Standard Namespace Template service catalog entry, including default
   quotas and baseline network policies.
4. The requesting team receives access credentials and a confirmation
   notice once provisioning completes.

Steps 1 and 2 must both be recorded before step 3 begins — provisioning
never starts on an unapproved request.
