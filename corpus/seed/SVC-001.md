# Service Catalog Entry: Standard Namespace Template

Provisions a new namespace with default quotas and network policies
aligned with the Network Segmentation and Ingress Standard, ready for a
team to deploy into immediately after approval.

**What it provisions:** a namespace provisioned with default quotas
(matching the Namespace Request and Quota Policy's standard default), and
network policies aligned with the Network Segmentation and Ingress
Standard applied automatically — namespace-to-namespace traffic denied by
default, with the requesting team able to add explicit allow policies
afterward as needed.

**How to request it:** via the Namespace Onboarding Procedure; this
template is what step 3 of that procedure provisions from once a request
is approved.
